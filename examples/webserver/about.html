🦀 IOk
Simple, Fast, Interpreted Programming Language

🚀 What is IOk?

IOk is a simple, interpreted programming language implemented in Rust. It focuses on ease of use and performance, making it perfect for learning, scripting, and rapid prototyping.

🎯 Key Features

📝 Simple Syntax

Clean, readable syntax inspired by modern languages

⚡ High Performance

Fast interpreter built with Rust performance optimizations

🌐 Network Ready

Built-in socket support for client/server applications

📚 Rich Standard Library

Comprehensive functions for I/O, networking, and data manipulation

💻 Example Code

// Hello World in IOk
write("Hello, World!")
// Socket programming
import std::net
let server = net::bind("127.0.0.1", 8080)
let client = net::connect("127.0.0.1", 8080)
client.write("Hello from IOk!")

🛠️ Language Features

Dynamic Typing

Variables can hold any type without declaration

First-Class Functions

Functions are values that can be passed and returned

Struct Support

Define custom data structures with methods

String Methods

Built-in methods like .includes(), .len(), .push()
